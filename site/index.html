The difference between free and usable.

Your cluster has 16 free slots. But the first queued job needs four adjacent slots within one rack. The largest available run is only two, so strict FIFO cannot start it. Switch to backfill to see smaller jobs use some of the gaps while the larger job waits.

    02 / UNDER THE HOOD

    SchedLab starts with a deliberately small model. Every simplification is visible, so you know what an experiment actually demonstrates.

    01 /

    A small, explicit cluster

    Four racks with eight abstract slots each. Jobs request a contiguous segment of slots within a single rack. This is a teaching constraint, not a claim about physical GPU adjacency.

    02 /

    Two scheduling choices

    Strict FIFO blocks behind the first unplaceable job. Opportunistic backfill may dispatch later jobs that fit. This demo does not model reservations or starvation guarantees.

    03 /

    Reproducible exploration

    Reset to replay the same scenario with different heuristics. Compare free capacity, largest allocatable block, queue length, and dispatch behavior.
